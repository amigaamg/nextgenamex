# AMEXAN Design System

Vercel-ready Next.js design system for AMEXAN Clinical Intelligence Operating System.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Deploy on Vercel

The easiest way to deploy is using the [Vercel Platform](https://vercel.com/new).
